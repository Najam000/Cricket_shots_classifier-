## 📋 About This Project

This repository contains the **Machine Learning Project Data Collection Form** for NAVTTC's
AI Batch III (Evening). The form collects all required student project data including:

- ✅ Student identification & contact information  
- ✅ Project title, objectives, and problem statement  
- ✅ Dataset source, size, features and preprocessing plan  
- ✅ Tools, frameworks and libraries used  
- ✅ Project timeline and weekly milestones  
- ✅ ML algorithms planned and evaluation metrics  
- ✅ Declaration and final submission

## 🚀 Run Locally

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/ML_DataCollection_BatchIII.git
cd ML_DataCollection_BatchIII

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the Streamlit app
streamlit run app.py
```

App will open at: `http://localhost:8501`
